# 无人机基本概念与动力选型分析

> 来源：《1-无人机基本概念》 + 《3-动力系统分析与选型》

# 一、无人机基本概念

## 1.1 飞行器种类

飞行器种类包括：**固定翼、多旋翼、垂直起降（VTOL）、直升机、仿生扑翼**等。

| 类型 | 姿态控制方式 | 起降要求 |
|------|-------------|----------|
| 固定翼 | 控制舵面 | 需跑道 |
| 多旋翼 | 控制电机转速 → 螺旋桨转速 | 垂直起降，无需跑道 |
| VTOL（复合翼/倾转旋翼） | 起降阶段旋翼控制，巡航阶段舵面控制 | 垂直起降 |
| 直升机 | 旋翼变距 + 尾旋翼 | 垂直起降 |

---

## 1.2 固定翼飞行器

### 组成结构
机身、机翼、水平尾翼、垂直尾翼、动力系统、控制系统

> 核心原理：推力系统产生向前的空速 → 机翼和机身产生升力。**需要跑道，不能垂直起降。**

### 各部件功能

| 部件 | 英文 | 功能 |
|------|------|------|
| 机身 | Fuselage | 连接各部件，承载载荷，也产生部分升力 |
| 机翼 | Wing | 提供主要升力，上有襟翼（Flap）、缝翼（Slat）、扰流板（Spoiler） |
| 副翼 | Aileron | 控制**滚转**——左右机翼升力差产生滚转力矩 |
| 水平尾翼 | Horizontal Stabilizer | 控制**俯仰**稳定性 |
| 垂直尾翼 | Vertical Stabilizer | 控制**航向**稳定性 |
| 升降舵 | Elevator | 平尾上的舵面，偏转后改变俯仰力矩 → **俯仰变化** |
| 方向舵 | Rudder | 垂尾上的舵面，偏转后产生侧向力 → **偏航力矩** |

---

## 1.3 多旋翼飞行器

> 核心原理：通过螺旋桨产生的拉力直接起飞，**无需跑道**。

### 三大系统

```
多旋翼无人机
├── 机架：机身、机臂、起落架
│   ├── 机身：承载平台，在保证性能下尽可能轻
│   ├── 机臂：关键参数是轴距（电机轴外接圆直径）
│   └── 起落架：减震、支撑、保持水平、减少地效
├── 动力系统：电机、电调、螺旋桨、电池
│   └── ⚠️ 各部件必须相互匹配兼容，否则可能电池过热起火
└── 控制系统：飞控、遥控器、接收机、GPS、数传、图传、地面站、机载电脑
```

### 控制系统详解

| 组件 | 功能 |
|------|------|
| **飞控（Autopilot）** | 控制姿态、位置和轨迹的核心，支持半自主/全自主 |
| **遥控器 + 接收机** | 飞控手指令 → 接收机解码 → 自驾仪控制多旋翼 |
| **GPS** | 定位，实现航线保持、自动飞行、悬停、一键返航 |
| **数传（Telemetry）** | 无线数据传输，地面站 ↔ 自驾仪双向通信 |
| **图传（Video Transmission）** | 摄像头画面实时无线回传 |
| **地面站（GCS）** | 规划航迹、监控飞行、修改参数（机型/PID等）、下载日志 |
| **机载电脑** | 机载计算平台 |

---

## 1.4 垂直起降飞行器（eVTOL）

### 三种构型对比

| 构型 | 特点 | 优缺点 |
|------|------|--------|
| **多旋翼型** | 无机翼，纯旋翼驱动 | 结构简单，速度慢，航程短，适合短途运输 |
| **复合翼型** | 独立升力旋翼 + 固定翼 + 推进器 | 安全性高，结构复杂，电机多，载重比低，成本高 |
| **倾转旋翼** ⭐ | 旋翼既提供升力也提供巡航推力 | 速度快、载重比高、性价比高、商业前景最好 |

### 倾转旋翼工作模式

```
多旋翼起飞 → 倾转加速 → 切换到固定翼 → 高速巡航 → 减速 → 切换回多旋翼
```

# 二、动力系统分析与选型

## 2.1 动力系统总览

**多旋翼动力系统 = 螺旋桨 + 电机 + 电调 + 电池**

> 核心原则：各部件必须**相互匹配和兼容**。如 6S 电池 + 16×8 二叶桨正常工作，换成三叶桨后负载增大可能导致电池过热起火。

---

## 2.2 螺旋桨

### 型号命名

**例：16×8 CCW**
- **16**：直径 16 英寸（1 英寸 = 25.4mm）
- **8**：螺距 8 英寸
- **CCW**：逆时针（CW = 顺时针）

### 关键参数

| 参数 | 说明 |
|------|------|
| **直径** | 决定拉力大小 |
| **螺距** | 决定每转前进距离 |
| **弦长** | 一般取半径 2/3 处的弦长 |
| **转动惯量** | 越小 → 电机响应越快 → 性能和效率越好 |
| **桨叶数** | 二叶桨效率最高；多叶桨拉力大但效率略降 |
| **安全转速** | 经验公式：$RPM_{max} = 105000 / 直径(英寸)$，如 10 英寸桨最大 10500 RPM |
| **力效** | = 拉力 / 机械功率 |
| **材料** | 碳纤维（轻、刚性好、贵）、塑料、木头（重、适合大载重） |

> ⚠️ 螺旋桨与电机匹配是关键：匹配良好 → 同等拉力下功耗更低 → 续航更长、发热更少

---

## 2.3 电机

### 类型选择
**外转子无刷电机**：力矩更大，易驱动大桨，速度更稳定。（内转子适用于其他场景）

### 关键参数

| 参数 | 说明 |
|------|------|
| **尺寸（如 4110）** | 前 2 位 = 定子直径(mm)，后 2 位 = 定子高度(mm)。越大 → 功率越大 |
| **KV 值** | 空载下 1V 电压对应的转速(RPM/V)。**低 KV = 大扭矩 → 驱动大桨**；高 KV = 小扭矩 → 驱动小桨 |
| **最大电流/功率** | 如 "25A/30s" = 持续 25A 安全，超 30s 可能烧毁 |
| **效率** | $\eta = P_{机械} / P_{电}$，非固定值，随油门和负载变化 |
| **总力效** | = 拉力(g) / 输入功率(W) = 螺旋桨力效 × 电机效率 |

---

## 2.4 电调（ESC）

### 功能
1. 依据飞控 PWM 信号控制电机转速（信号放大）
2. 无刷电调：直流 → 三相交流（换相器）
3. 可作制动器/稳压电源
4. 电池保护、启动保护

### 关键参数

| 参数 | 说明 |
|------|------|
| **最大持续/峰值电流** | 选型需留 **20% 安全裕度**，如 50A 电调留 10A 裕度 |
| **电压范围** | 如 "3-4S LiPo" = 11.1~14.8V |
| **刷新频率** | 越高 → 电机响应越快，多旋翼要求高刷新率 |

---

## 2.5 电池

### 基本概念
- 单体标称电压 **3.7V**，满电 **4.2V**
- 串联（S）= 增电压；并联（P）= 增容量
- 例：3S1P = 3 串 × 3.7V = **11.1V**，容量 = 单节容量
- 例：2S2P = 2 串 × 2 并 = **7.4V**，容量 = 2 倍单节容量

### 关键参数

| 参数 | 说明 |
|------|------|
| **容量（mAh）** | 5000mAh = 以 5A 放电可放 1 小时 |
| **放电倍率（C）** | 5000mAh + 20C → 最大放电电流 100A。⚠️ 多旋翼瞬时总电流不能超电池最大电流 |
| **内阻** | 大电流下分压明显，实际输出电压 < 标称值 |
| **安全阈值** | 必须设电压安全阈值保证返航，过度放电会损坏电池 |

### 电量检测方法
1. **检测电芯电压**（应用广，可传感器实时检测）
2. **实时检测荷电状态**（可实现性弱，传感器未普及）

## 2.6 动力系统选型（实战案例）

> 案例：四旋翼，起飞重量 7.5kg，轴距 1000mm，悬停 > 15min，悬停油门 < 55%

### 选型流程

```
确定起飞重量 → 计算单桨拉力 → 计算桨最大尺寸 → 选电机 → 配电调 → 选桨 → 选电池 → 验算悬停时间
```

### （1）单桨拉力计算

- 悬停总重 73.5N → 单桨拉力 $73.5 / 4 / \cos(姿态角) \approx 19.6\text{N}$
- 留安全裕度后：单桨最大拉力范围 **22.05N ~ 29.43N**

### （2）螺旋桨最大尺寸

由轴距限制（1000mm）和几何关系：
$$r_{max} = \frac{R \cdot \sin(\pi/n)}{1 + \mu}, \quad \mu = 0.18$$

解得最大直径范围 **30~34 英寸**（实际选用 16×8 三叶桨，未超限）

### （3）选电机

选择 **T-MOTOR V505**：
- 最大起飞重量 10~15kg
- 配 16×5.4 桨时，42% 油门即达 8kg 拉力
- 重量 255g，12S 电池，最大电流 52A

### （4）选电调

配 **FLAME 60A 12S**（持续电流 60A > 电机最大电流 52A）

### （5）选螺旋桨

考虑倾转旋翼兼顾多旋翼和固定翼模式，选 **16×8 三叶桨**

### （6）选电池

**格氏 12S1P**（2×6S 串联），容量 16000mAh

### （7）悬停时间验算

| 部件 | 重量 |
|------|------|
| 电池（2×6S） | 2130g |
| 电调 ×4 | 294g |
| 螺旋桨 ×4 | 52g |
| 电机 ×4 | 1020g |
| 其他（机架/飞控/配件） | 4500g |
| **总计** | **7996g ≈ 8kg** |

$$悬停时间 = \frac{C_b - C_{min}}{I_b} = \frac{16000 - 2400}{26.98} \times \frac{60}{1000} \approx 30.2\text{min}$$

> ✅ 远大于 15min 要求，绰绰有余！

# 三、关键公式速查

| 用途 | 公式 |
|------|------|
| 电机效率 | $\eta = P_{机械} / P_{电}$ |
| 总力效 | 总力效 = 拉力 / 输入功率 = 螺旋桨力效 × 电机效率 |
| 放电倍率 | 电流 = 容量 × C 倍率 |
| 安全转速 | $RPM_{max} = 105000 / D(英寸)$ |
| 机臂-旋翼半径关系 | $r_{max} = R \cdot \sin(\pi/n) / (1 + \mu)$ |
| 悬停时间 | $T = (C_b - C_{min}) / I_b$ |

# 四、核心要点总结

1. **多旋翼姿态控制** = 控制电机转速 → 控制螺旋桨转速 → 控制机身姿态
2. **动力系统匹配 > 单个部件性能**：电池、电调、电机、螺旋桨四者必须匹配
3. **低 KV 电机 = 大扭矩 = 大桨**；高 KV 电机 = 小扭矩 = 小桨
4. **选型从起飞重量出发** → 拉力需求 → 桨尺寸 → 电机 → 电调 → 电池 → 验算悬停
5. **安全裕度很重要**：电调留 20%、拉力留裕度、电池设安全电压阈值
6. **倾转旋翼（eVTOL）是商业应用的最佳构型**：兼具垂直起降和高速巡航能力
