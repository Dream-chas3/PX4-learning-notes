# FanciSwarm 树莓派无人机产品介绍

> 来源：https://fancinnov.com/FanciSwarm-RaspberryPi.html

---

## 一、产品概述

**FanciSwarm 树莓派套件**是 FanciSwarm 微型集群无人机技术的延伸，通过专为其设计的树莓派支架系统，将树莓派主板和配套摄像头集成到无人机平台上，为无人机提供**先进的智能感知和导航能力**。

- 调试安装好，**整机发货**，到手即用
- 支持**二次开发**，配套 Python 工程源码
- 主板兼容从低功耗（Zero 2W）到高性能（Pi 5）多种型号

---

## 二、套件组成

| 组件 | 说明 |
|------|------|
| **FanciSwarm 微型集群无人机** | 核心飞行平台，含飞控、电机、桨叶、电池等基础平台 |
| **树莓派专用支架系统** | 定制支架，将树莓派稳固固定在无人机上 |
| **树莓派主板** | 兼容 Zero 2W、Pi 5 等多种型号 |
| **配套摄像头模块** | 可朝前或朝下两种方向安装 |

---

## 三、硬件规格

### 3.1 飞控平台

| 项目 | 参数 |
|------|------|
| **飞控** | Mcontroller® |
| **MCU** | ST STM32H743 系列 |
| **操作系统** | FreeRTOS 实时操作系统 |
| **电机间距** | 80mm |
| **桨叶** | 3 英寸（3020L / 3020R） |

### 3.2 本机传感器

| 传感器 | 型号/参数 | 功能 |
|--------|-----------|------|
| **IMU** | 飞控集成（加速度计 + 陀螺仪） | 测量三轴角速度和加速度 |
| **气压计** | 飞控集成 | 测量气压 → 推算高度 |
| **激光测距** | ToF 方案，量程 4m，频率 50Hz，I2C 接口 | 低空精确测距 |
| **光流模块** | 检测 X/Y 平面位移 | 辅助悬停，无 GPS 时位置保持 |
| **摄像头** | 配套摄像头，前视 / 俯视两用 | 图像识别、YOLO 检测、Aruco 引导降落 |

### 3.3 UWB 定位

| 项目 | 参数 |
|------|------|
| **定位模块** | DWM1000 |
| **定位精度** | < 10cm |
| **基站数量** | 4 个 |
| **支持模式** | 轨迹飞行、编队飞行、集群飞行 |

### 3.4 树莓派与摄像头

| 项目 | 说明 |
|------|------|
| **兼容主板** | Raspberry Pi Zero 2W（高效节能）、Pi 5（性能强劲），及其他多种型号 |
| **摄像头朝前安装** | 捕捉前方视野 → 目标跟踪、视觉导航 |
| **摄像头朝下安装** | 监测下方环境 → 视觉降落、地面巡检 |

## 四、核心功能

### 4.1 视觉感知

配套完整的无人机智能感知与导航实例源码，**支持 Python 控制**：

| 能力 | 技术方案 | 说明 |
|------|----------|------|
| **图像识别** | OpenCV + Python | 实时图像处理与分析 |
| **目标检测与跟踪** | YOLO | 深度学习目标检测，智能跟随 |
| **视觉引导降落** | Aruco 码识别 | 识别 Aruco 标记实现精准着陆 |

### 4.2 UWB 室内定位与集群

搭配四个 UWB 基站，实现高精度室内三维定位，支持：

| 飞行模式 | 说明 |
|----------|------|
| **轨迹飞行** | 单机按预设轨迹自主飞行 |
| **编队飞行** | 多机保持固定队形飞行 |
| **集群飞行** | 多机协同，组网协作 |

## ⚠️ 电池安全

1. 不使用时**务必断开电池与飞控扩展板的连接**
2. 充满电后**及时从充电器拔掉电池**
3. 电量过低时无人机会发出**"嘟嘟嘟…"**报警声，需及时充电或更换电池
4. 长期不用时电池保持 **7.6V~7.7V** 存储
5. 放电不低于 **6.4V**（过放造成永久损伤）
6. 禁止使用鼓包、漏液、破损电池
7. 远离高温（>50°C）、保持干燥
