# FanciSwarm 快速开发指南

> 来源：https://fancinnov.com/support-FanciSwarm.html
> 涵盖：快速入门 → 飞行操作 → UWB 轨迹飞行 → 集群飞行 → 组网配置

---

## 一、快速入门

### 1.1 认识你的 FanciSwarm

- **结构**：最新款已完成结构升级，搭载高性能无刷电机，相邻电机间距 80mm
- **集成模块**：UWB（DWM1000）、激光测距（ToF）、光流模块
- **飞控**：Mcontroller® 跨模态飞控，共 8 个 LED 指示灯（LED0~LED7）
- **机头方向**：参照结构示意图确定
- **警报提示音**：用于判断上电、解锁、启动、上锁、数据链连接及异常状态

### 1.2 电池使用（⚠️ 重要）

**充电**：
- 通过充电转接线连接充电器
- 未充满：LED 红色；充满：全部变绿
- **充满后务必及时断开充电器**

**更换电池**：
1. 拔掉电池，断开与飞控扩展板的连接
2. 从电池尾部向头部方向推动取出旧电池
3. 新电池头部朝向扩展板电源线方向，推入电池槽，连接电源线

**安全红线**：
- 不用无人机时**务必断开电池连接**
- 禁止使用鼓包、漏液、破损电池
- 放电**不低于 6.4V**（过放永久损伤）
- 禁止高于 50°C 环境存放
- 长期不用：电压维护至 **7.6V~7.7V**

### 1.3 microSD 卡

- 出厂前已在飞控内部安装好
- 金属接触面朝上，插入 Mcontroller 飞控尾部卡槽，听到"咔"声即安装到位
- 取出：挤压卡尾部弹出
- 支持 HC / XC 类型，无容量限制

> ⚠️ 飞行日志对分析异常至关重要，无日志可能无法提供技术支持或保修服务。

### 1.4 安装 FanciSwarm App

| 平台 | 版本 | 更新日期 | 下载方式 |
|------|------|----------|----------|
| **Android** | V1.3.6 | 2026-01-14 | 官网下载 APK 安装 |
| **iOS** | V1.3.2 | 2024-12-12 | App Store（需 iOS 13.0+） |

App 功能：参数实时配置、体感/摇杆操控、数据监测、传感器校准、一键起飞/降落。搭配 Mlink-video 可实时图传、拍照录像。

### 1.5 安装图传（可选）

若选配 Mlink-video 图传模组：
1. 将四根杜邦母头按线序接插到无人机四个插针上（**务必正确，不可接反**）
2. 通过双面胶块将图传粘贴在 Mcontroller 飞控外壳上

### 1.6 开启电源

1. 将飞控扩展板电源连接口与电池供电头连接（双电版需两块电池都连接）
2. 拨动开关到 **"一"** 位置

### 1.7 连接 FanciSwarm

#### App 连接（未装图传）

1. 手机连接 WiFi：名称 `Mlink-XXXX`，密码 `1234567890`
2. 打开 App，点击左侧图标，默认输入 id 为 `0`，点击确认

> ⚠️ 连接前关闭手机"网络加速""双 WiFi 加速""智能切换网络"等功能

#### App 连接（已装图传）

1. 手机连接 Mlink-video 的 WiFi（无密码）
2. 打开 App，等待 1-2 秒后点击 Start 即可获取图像

#### 遥控器连接

1. 确保接收机正确安装，长按遥控器电源按钮 1 秒开机
2. 成功连接：接收机指示灯由**闪烁变长亮**，Mcontroller 左侧黄灯（LED2）由**快闪变慢闪**

### 1.8 水平校准

将无人机放在水平桌面上，通过 App 设置界面点击水平校准按钮。校准成功时按钮文字短暂显示"校准成功"。

## 二、飞行前检查（⚠️ 必读，逐项核对）

| 序号 | 检查项 | 要求 |
|------|--------|------|
| 1 | 放置面 | **水平面**，用户面朝机尾 |
| 2 | 周围空间 | 前后左右 **2m 范围内**空旷，无墙壁、无杂物 |
| 3 | 地面纹理 | **必须有清晰可识别纹理**，纯色/过暗/过亮/强反光地面**禁止起飞** |
| 4 | 特殊地面 | 大理石瓷砖、木地板、重复纹理方格图案**严禁起飞** |
| 5 | 地垫 | 使用附赠帆布地垫平铺于地面 |
| 6 | 电池连接线 | 确保不会被螺旋桨刮到 |
| 7 | 螺旋桨 | 正确牢固安装，无破损老化变形 |
| 8 | 电量 | 无人机、手机或遥控器电量充足 |
| 9 | 版本 | 固件版本和 App 版本与官网一致 |

## 三、飞行操作

### 3.1 使用 App 飞行

#### 一键起飞（8 步）

1. 连接成功后点击 Start 进入主界面
2. 确认摇杆样式为四通道摇杆，模式为**位置模式**
3. 认识主界面图标
4. **硬件解锁前检查**：确认起落架稳固；将飞机垂直拿起超过 1m 后放下，确认激光测距正常
5. 点击右上方**锁定按钮**进行硬件解锁（LED 绿灯点亮）
6. 点击 **QC 快捷命令**按钮
7. 长按**一键起飞**按钮 1.5 秒直至圆形进度条闭合
8. 无人机缓慢上升，完成起飞

#### 飞行中操控

- 长按摇杆感受到振动反馈后拖动摇杆操控
- 松手后摇杆自动回中
- **锁定按钮为绿色时切勿长按**，否则电机会在空中停转
- 位置模式下最大飞行高度 **2m**

#### 一键降落

1. 点击 QC 按钮，长按一键降落按钮 1.5 秒
2. 着陆后电机停转，长按锁定按钮 2 秒完成锁定
3. 拨动开关到 **"0"** 位置，断开电池连接

### 3.2 使用遥控器飞行

#### 起飞

- CH7 三段开关和 CH5 三段开关调至**中段**
- CH7 上档为**手动姿态模式**（不熟练的用户**严禁使用**）
- 点击 CH6 按钮解锁
- 油门摇杆拉到**右下方**持续约 3 秒，螺旋桨开始转动后回中
- 缓慢上推油门起飞，起飞后及时回中

#### 降落

- 缓慢下拉油门至着陆，长按 CH6 按钮 2 秒锁定
- 关闭无人机和遥控器，断开电池

### 3.3 关闭电源

拨动开关到 **"0"** 位置，**务必断开电池连接**。

## 四、UWB 轨迹飞行（单机）

### 4.1 环境准备

- Ubuntu 20.04 + ROS Noetic
- 安装依赖：

```bash
sudo apt-get install ros-noetic-serial
sudo apt-get install libeigen3-dev
```

### 4.2 ROS 工程搭建

```bash
mkdir -p ~/ros-ws/src
cd ~/ros-ws/src
git clone https://gitee.com/fancinnov/fcu_core.git
git clone https://gitee.com/fancinnov/quadrotor_msgs.git
cd ~/ros-ws
catkin_make
```

### 4.3 通信节点配置

编辑 `fcu_core/src/fcu_bridge_001.cpp`：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `BUF_SIZE` | 通信缓冲区大小 | 32KB |
| `BAUDRATE` | 串口波特率 | 460800 |
| `DRONE_PORT` | 网络通信端口 | 333 |
| `DRONE_IP` | **必须填 WiFi 模块的 IP** | `192.168.4.1` |
| `USB_PORT` | 串口设备 | `/dev/ttyACM0` |
| `mavlink_channel_t` | 通信方式：0=USB串口, 1=网络 | 默认 1（网络） |
| `offboard` | 是否使用机载计算机 | false |
| `use_uwb` | 是否使用 UWB 基站 | true |
| `set_goal` | 是否远程 PC 设目标点 | true |

### 4.4 轨迹设计

在 `fcu_mission.cpp` 中定义轨迹点，默认飞圆形轨迹，起点坐标 (3, 2)。

### 4.5 键盘控制指令

在终端输入单字符 + 回车：

| 指令 | 作用 |
|------|------|
| `a` | 解锁（Arm） |
| `t` | 起飞（Takeoff） |
| `r` | 运行轨迹（Run） |
| `s` | 停止轨迹（Stop） |
| `l` | 降落（Land） |
| `d` | 锁定（Disarm） |

### 4.6 执行流程

1. **飞行测试**（基站关闭）— 先用 App 或遥控器确认飞行稳定
2. 配置组网模块（Mlink-esp WiFi）
3. 配置电脑环境（Ubuntu + ROS）
4. 导入 ROS 工程
5. 配置通信节点参数
6. 设计轨迹
7. 编译：`catkin_make`
8. 摆放 4 个 UWB 基站
9. 设置定位参数（标签 ID = 1）→ **重启无人机**
10. 放置无人机在轨迹起点
11. 重启无人机并开启基站 → 确认 LED6 **快速闪烁**
12. 运行：`roslaunch fcu_core fcu_core.launch`
13. RViz 确认轨迹
14. 飞行前检查
15. 基站开启下飞行测试
16. 键盘指令执行轨迹

## 五、集群飞行（以 3 台为例）

### 5.1 准备工作

1. 依次对 1~3 号无人机进行飞行测试（基站关闭）
2. 每台无人机配置 WiFi 组网模块（Station 模式 + 固定 IP）
3. 电脑环境同上（Ubuntu 20.04 + ROS Noetic）

### 5.2 通信节点

需要三个通信节点文件：
- `fcu_bridge_001.cpp` → 无人机 1（标签 ID=1）
- `fcu_bridge_002.cpp` → 无人机 2（标签 ID=2）
- `fcu_bridge_003.cpp` → 无人机 3（标签 ID=3）

### 5.3 轨迹起点（默认）

| 无人机 | 标签 ID | 起点坐标 |
|--------|---------|----------|
| 1 号 | 1 | (3, 2) |
| 2 号 | 2 | (2.5, 2.866) |
| 3 号 | 3 | (1.5, 2.866) |

### 5.4 执行流程

1. 每台单独飞行测试
2. 配置组网模块
3. 配置电脑环境
4. 导入 ROS 工程 + 配置 3 个通信节点
5. 设计轨迹
6. 编译
7. 摆放基站 + 设置定位参数（标签 ID=1/2/3）
8. 每台放到各自轨迹起点，机尾朝用户
9. 重启所有无人机 + 基站
10. 运行 `roslaunch fcu_core fcu_core.launch`
11. **先对每台单独做轨迹测试**，确认全部正常
12. 开启所有无人机，键盘指令控制集群飞行
13. 同样键盘指令：`a` 解锁 → `t` 起飞 → `r` 运行 → `s` 停止 → `l` 降落 → `d` 锁定

## 六、WiFi 组网模块配置

### 6.1 方法一：Mlink-esp 调试器（推荐）

**1.** 从无人机上取下 Mlink-esp WiFi 模块  
**2.** 将模块连接到 Mlink-esp 调试器（⚠️ **请勿接反，接反必烧！**）  
**3.** 下载串口助手 → 解压得到 `sscom5.13.1.exe`  

> Linux 用户安装替代工具：`sudo apt-get install cutecom`

**4.** 打开串口助手，选择端口 `...USB-SERIAL CH340`，波特率 `115200`  
**5.** 依次发送 AT 指令：

| 顺序 | 指令 | 作用 |
|------|------|------|
| 1 | `AT+RST` | 重启模块 |
| 2 | `AT+RESTORE` | 恢复出厂设置 |
| 3 | `AT+CWMODE_DEF=1` | 设为 Station 模式 |
| 4 | `AT+CWJAP_DEF="WiFi名","密码"` | 连接路由器（**WiFi名不能是中文**） |
| 5 | `AT+CIFSR` | 查询 IP 地址 |
| 6 | `AT+CIPSTA_DEF="192.168.0.100","192.168.0.254","255.255.255.0"` | 设置固定 IP |
| 7 | `AT+CIFSR` | 再次确认 IP 生效 |

看到 `WIFI CONNECTED` 和 `WIFI GOT IP` 即配置成功。

### 6.2 方法二：修改固件

> 不取下 WiFi 模块，保持模块连接无人机，通过修改固件进入配置模式。

**步骤**：

1. 下载固件工程和依赖包（`/download-FanciSwarm-after1120`）
2. 修改 `Clibrary/include/config.h`：
   ```c
   // 改前
   #define COMM_0 MAV_COMM
   // 改后
   #define COMM_0 CONFIG_COMM
   ```
3. 重新编译，生成新 `.hex`
4. 烧录到 FanciSwarm（STM32CubeProgrammer V2.15）
5. 通过 USB 连接无人机，串口助手发 AT 指令（同上表）
6. ⚠️ **配置完成后必须改回来**：
   ```c
   #define COMM_0 MAV_COMM  // 恢复 MAVLink 模式
   ```
7. 重新编译并再次烧录

## 七、定位参数设置（关键）

### 基站摆放

- 4 个基站标注 id 编号（1~4），按顺序放置
- 基站高度**大于无人机飞行高度**
- 无人机飞行轨迹距离任何一个基站需 **> 2m**
- 基站距离墙壁/天花板/金属物体需 **> 15cm**

### 参数清单

| 参数 | 说明 |
|------|------|
| 坐标偏航角 | UWB 坐标系与飞行区域的偏转角度 |
| 标签 ID | 从 1 开始，不同飞机不同编号 |
| 标签总数 | 等于实际开机无人机数量 |
| 基站 1~4 坐标 | 基站 (x, y, z) 坐标，单位 cm |

> ⚠️ 设置完定位参数后**务必重启无人机**才能生效。

### 参考基站坐标

| 基站 | X (cm) | Y (cm) | Z (cm) |
|------|--------|--------|--------|
| 1 | 80 | -80 | 160 |
| 2 | 0 | 400 | 170 |
| 3 | 400 | 400 | 170 |
| 4 | 400 | 0 | 170 |

## 八、安全机制

| 保护类型 | 触发行为 |
|----------|----------|
| **撞击保护** | 自动锁停电机 |
| **信号丢失保护** | 自动下降着陆 |
| **电量过低保护** | 自动降落（默认 < 6.4V 告警） |
| **最大高度限制** | 位置模式下 2m |
| **遥控器油门** | 始终有效（0.4~0.6 为悬停区间） |

## 十、常见问题

| 问题 | 可能原因 | 解决 |
|------|----------|------|
| 无法连接 App | 手机开启了网络加速 | 关闭"双 WiFi 加速""智能切换网络" |
| 光流定位不稳 | 地面纹理不清 | 使用附赠帆布地垫 |
| 磁力计异常 | 强磁场干扰 | 重新校准磁力计（远离电子设备，手持做"倒8字"翻转 + 原地转圈） |
| UWB 定位不准 | 基站被遮挡 / 距离太近 | 调整基站位置；确保无人机距离每个基站 > 2m |
