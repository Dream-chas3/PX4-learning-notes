# 激光与超声波测距传感器

> 测距传感器提供**高精度、短距离**的距离测量（几厘米到几十米），用于**低空定高、避障、降落检测、地形跟随**。本固件支持三种技术：ToF 激光（VL53）、LiDAR 激光（TFmini）、超声波（HC-SR04）。

## 一、原理介绍

### 1.1 三种测距技术对比

| 传感器 | 原理 | 量程 | 精度 | 接口 | 用途 |
|---|---|---|---|---|---|
| **VL53L0X/VL53L1X** | ToF 光飞行时间 | 2m / 4m | ±1cm | I2C | 低空定高 |
| **TFmini/TF2mini** | LiDAR 光飞行时间 | 12m | ±1cm | UART/I2C | 中低空测距 |
| **HC-SR04** | 超声波回波 | 4m | ±3mm | GPIO | 备用测距 |

### 1.2 光飞行时间（ToF）原理

激光测距的核心是 **ToF（Time of Flight，飞行时间法）**：

```
距离 d = c · t / 2
```

- 发射一束红外激光（VL53 用 940nm VCSEL）
- 记录光从发射到被物体反射回来的时间 t
- 光速 c ≈ 3×10⁸ m/s，除以 2（往返）

VL53 系列用 **SPAD（单光子雪崩二极管）** 阵列直接检测光子到达时间，抗环境光干扰强；TFmini 用 **脉冲激光 + 光电二极管** 检测。

### 1.3 超声波原理

超声波测距发射 40kHz 超声波，测回波时间，同样用 ToF，但介质是**声波**（声速 340m/s，远慢于光速）。适合近距离，但受温度、风向影响大。

## 二、硬件接口

| 传感器 | 接口 | 引脚/端口 |
|---|---|---|
| VL53L0X/VL53L1X | I2C | 板载 I2C2（PB10/PB11） |
| TFmini | UART | `TFMINI_COMM`（可配置到某串口） |
| TF2mini | I2C | 板载 I2C（`get_i2c_tf2mini_data`） |
| HC-SR04 | GPIO | Trig/Echo 引脚（`HC_SR04_trig/echo`） |

> [!note] 串口配置
> config.h 里定义了 `TFMINI_COMM`（TFmini 激光）和 `TF2MINI_COMM`（TF2mini 激光）两种串口模式，可分配到 COMM_0~COMM_4。

## 三、数据结构

`hal.h` 中定义（LC302 是光流，见单独笔记；这里只列测距相关）：

```c
// VL53 / TFmini 的距离通过函数传递，没有独立结构体，而是进入 EKF_Rangefinder
```

测距数据主要进入 `Rangefinder_state`（[common.h](Maincontroller/inc/common.h)）：

```c
typedef struct {
    bool enabled=false;
    bool alt_healthy=false;   // 是否可信（无 glitch）
    float alt_cm=0.0f;        // 倾斜补偿后的高度 cm
    uint32_t last_healthy_ms=0;
    uint32_t last_update_ms=0;
    LowPassFilterFloat alt_cm_filt;  // 高度低通滤波
    int8_t glitch_count;      // 毛刺计数
} Rangefinder_state;
```

## 四、驱动代码解读

### 4.1 驱动函数（hal.h 声明）

### 4.2 调用流程

**初始化**（[freertos.c InitTask](Core/Src/freertos.c#L327-L328)）：

```cpp
vl53lxx_init();   // VL53 激光测距
// ...
tf2mini_init();   // TF2mini
```

**数据采集**（[freertos.c Loop50hzTask](Core/Src/freertos.c#L438-L457)，50Hz）：

```cpp
void Loop50hzTask(void *argument){
    // ...
    vl53lxx_update();        // 更新 VL53 测距
    get_i2c_tf2mini_data();  // 读 TF2mini
    // ...
}
```

### 4.3 数据流

```
vl53lxx_update() ──► get_vl53lxx_data(distance_mm) ──► rangefinder_state.alt_cm
                                                       ──► EKF_Rangefinder ──► 高度
```

EKF_Rangefinder 对象（[maincontroller.cpp](Maincontroller/src/maincontroller.cpp#L115)）：

```cpp
EKF_Rangefinder *ekf_rangefinder = new EKF_Rangefinder(_dt, 1.0, 0.000016, 0.16);
//                                                      dt   Q    R_pos     R_vel
```

### 4.4 毛刺（Glitch）处理

激光测距在飞过物体边缘/反光面时会跳变，固件有专门处理（[common.h](Maincontroller/inc/common.h)）：

```c
#define RANGEFINDER_GLITCH_ALT_CM  50.0f  // 超过 50cm 的变化视为毛刺
#define RANGEFINDER_GLITCH_NUM_SAMPLES  50  // 连续 50 次毛刺才采信新读数
#define RANGEFINDER_TIMEOUT_MS  1000     // 超时重置
```

在 mode 代码里（如 [mode_poshold.cpp](Maincontroller/src/mode_poshold.cpp#L245)）起飞后 10 秒内禁用 glitch 检测：

```cpp
if((HAL_GetTick()-takeoff_time)<10000){//起飞10s内禁止glitch
    rangefinder_state.glitch_count=0;
}
```

## 五、应用场景

| 场景 | 说明 |
|---|---|
| **地形跟随** | `get_surface_tracking_climb_rate()` 用测距仪保持离地高度 |
| **降落检测** | `LAND_RANGEFINDER_MIN_ALT_CM 200` 检测是否接近地面 |
| **降落速度限制** | autonav 里 `rangefinder_state.alt_cm<200` 时减速 |

## 六、要点总结

1. 测距传感器是**低空高度**的关键，补充气压计的低空盲区
2. VL53（ToF/I2C）与 TFmini（LiDAR/UART）技术相同、接口不同
3. 数据进入 `Rangefinder_state` 经毛刺处理后融合进 `EKF_Rangefinder`
4. 超声波 HC-SR04 有驱动接口但默认未启用（config 无对应开关）
