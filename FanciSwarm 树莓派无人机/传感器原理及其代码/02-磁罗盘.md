# 磁罗盘（Magnetometer）

> 磁罗盘（磁力计）测量地球磁场方向，用于**校正航向角（yaw）**。陀螺仪积分出的 yaw 会长期漂移，磁力计提供绝对航向参考，是长期航向稳定的关键。

## 一、原理介绍

### 1.1 测量原理

磁力计测量地磁场矢量。常见原理：

| 原理 | 说明 | 代表型号 |
|---|---|---|
| **磁阻效应（AMR）** | 材料电阻随磁场方向变化，用惠斯通电桥检测 | HMC5883/QMC5883 |
| **霍尔效应** | 电流在磁场中产生横向电压 | 部分集成磁力计 |

地磁场是一个从磁南极指向磁北极的矢量。当磁力计固定在机体上，测量到的磁场在机体坐标系的分量，结合姿态（roll/pitch）就能算出**航向角**：

```
磁力计机体测量值 + 姿态(roll/pitch) ──► 磁场水平分量 ──► yaw = atan2(Hy, Hx) + 磁偏角
```

### 1.2 磁偏角（Declination）

**地理北极 ≠ 地磁北极**，两者夹角叫磁偏角。真航向 = 磁航向 + 磁偏角。本固件通过 `declination`（`AHRS::set_declination`）修正，`compass/declination.h` 提供全球磁偏角模型。

### 1.3 本固件支持的型号

| 型号 | 厂商 | 说明 |
|---|---|---|
| **QMC5883L** | 矽睿科技（QST） | 3 轴 AMR 磁力计，HMC5883 兼容 |
| **LSM303D** | ST | 3 轴磁力计 + 3 轴加速度计 |
| **MPU9250 内置磁** | TDK | MPU9250 集成的 AK8963 磁力计 |

## 二、硬件接口

磁力计挂在 **I2C** 总线上（[Core/Src/i2c.c](Core/Src/i2c.c)）：

```
I2C2（板载）: PB10 → I2C2_SCL, PB11 → I2C2_SDA   → 主磁罗盘
I2C1（外部扩展）: PB7 → I2C1_SDA, PB8 → I2C1_SCL  → 外部磁罗盘(MAG2)
```

I2C 配置（[i2c.c:45-57](Core/Src/i2c.c#L45-L57)）：

| 参数 | 值 |
|---|---|
| 模式 | 主机，快速模式 400kHz |
| 地址 | 7 位寻址 |
| Timing | 0x00901850（对应 400kHz） |
| 滤波 | 模拟滤波使能 + 数字滤波 |

> [!tip] 两个磁罗盘
> 固件支持**双磁罗盘**：`MAG_Init/MAG_Get_Data`（主磁罗盘）和 `MAG2_Init/MAG2_Get_Data`（外部扩展磁罗盘）。板载磁罗盘易受电机/大电流干扰，外置磁罗盘远离干扰源更准。

## 三、数据结构

`hal.h` 中定义：

```c
typedef struct{
    Vector3_Int16 mag_raw;   // 原始磁力计读数
    Vector3_Float magf;      // 换算后磁场强度（高斯 gauss）
    int16_t temp;            // 温度
}QMC5883_Data;

typedef struct{
    Vector3_Int16 acc_raw;   // LSM303D 还带加速度计
    Vector3_Int16 mag_raw;
    Vector3_Float accf;      // m/s²
    Vector3_Float magf;      // gauss
    int16_t temp;
}LSM303D_Data;
```

> 注意单位是**高斯（gauss）**，与其他 IMU 的磁力计（uT）不同。

## 四、驱动代码解读

### 4.1 驱动函数（hal.h 声明）

```c
void MAG_Init(void);        // 主磁罗盘初始化
void MAG_Get_Data(void);    // 主磁罗盘读取
void MAG2_Init(void);       // 外部磁罗盘初始化
void MAG2_Get_Data(void);   // 外部磁罗盘读取
```

### 4.2 调用流程

**初始化**（[freertos.c InitTask](Core/Src/freertos.c#L309-L347)）：

```cpp
MAG_Init();      // 主磁罗盘
// ...
MAG2_Init();     // 外部磁罗盘
```

**数据采集**（[freertos.c MagTask](Core/Src/freertos.c#L648-L664)，100Hz）：

```cpp
void MagTask(void *argument){
    vTaskDelayUntil(&PreviousWakeTime, TimeIncrement);  // 10ms → 100Hz
    MAG_Get_Data();    // 读主磁罗盘
}
```

**外部磁罗盘**在 [Loop50hzTask](Core/Src/freertos.c#L438-L457) 里读取：

```cpp
void Loop50hzTask(void *argument){
    // ...
    MAG2_Get_Data();   // 50Hz 读外部磁罗盘
}
```

### 4.3 数据流

```
MagTask(100Hz) ──► MAG_Get_Data() ──► _mag_filter(低通 5Hz) ──► AHRS 磁观测校正 ──► 航向
```

滤波参数（[maincontroller.cpp](Maincontroller/src/maincontroller.cpp)）：

```cpp
static float mag_filt_hz = 5;    // 磁力计低通滤波截止频率
static LowPassFilterVector3f _mag_filter;
```

## 五、校准（重要）

磁力计极易受**硬磁干扰（Hard Iron，机体上的永磁/铁磁材料）**和**软磁干扰（Soft Iron）**影响，必须校准：

- **校准器**：`CompassCalibrator`（`compassCalibrator` 对象）
- **方法**：绕各轴旋转，采集数据做**椭圆/椭球拟合**，求零偏和比例
- **参数**（`common.h`）：`mag_offsets`（零偏）、`mag_diagonals`（比例）、`mag_offdiagonals`（耦合）

> [!warning] 校准时机
> 磁罗盘校准必须在电机**不转**、远离磁性物体时进行。电机转动产生的交变磁场会严重干扰磁罗盘（工程里叫 "compassmot" 干扰）。

## 六、要点总结

1. 磁力计提供**绝对航向参考**，修正陀螺仪 yaw 的长期漂移
2. 支持双磁罗盘（板载 + 外置），外置抗干扰更好
3. 磁偏角修正 + 椭圆校准是获得准确航向的前提
4. 单位是**高斯**（gauss），数据经 5Hz 低通滤波后进入 AHRS
