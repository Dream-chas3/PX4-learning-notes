# 开发流程

> 本文总结个人无人机开发的完整流程，从**零基础**到 **FanciSwarm 树莓派无人机二次开发**。

## 二、核心开发工作流（工程闭环）

从「看懂代码」到「飞机飞起来」的实战闭环：

```
  ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
  │  源码学习     │ →  │  环境搭建     │ →  │  仿真验证     │
  │  架构分层     │    │  SITL/Gazebo │    │  QGC 监视     │
  └──────────────┘    └──────────────┘    └──────┬───────┘
        ▲                                          │
        │                                          ▼
  ┌─────┴─────────┐                        ┌──────────────┐
  │  日志分析/调参  │ ←──────────────────── │  飞控执行     │
  │  param / 日志  │                        │  姿态/位置控制 │
  └───────────────┘                        └──────┬───────┘
                                                  ▲
                                                  │
                                         ┌────────┴───────┐
                                         │  MAVROS 桥接    │
                                         │  (统一 MAVLink) │
                                         └────────┬───────┘
                                                  ▲
                                                  │
                                         ┌────────┴───────┐
                                         │  编写 ROS 节点  │
                                         │  offboard 控制 │
                                         └────────────────┘
```

> 💡 关键认知：**你的 ROS 节点并不直接控制电机**，它只是通过 MAVROS 这座「桥」，把位置/速度指令翻译成 MAVLink 消息发给飞控，由飞控内部完成 EKF→位置→姿态→速率→混控→电机的完整解算。

## 三、技术栈分层

| 层 | 技术 | 作用 | 对应笔记 |
| --- | --- | --- | --- |
| **应用层** | ROS / MAVROS / Offboard | 上层任务、定点/轨迹飞行 | ⑤ 进阶学习、⑦ 开发总结 |
| **飞控层** | PX4 / Mcontroller-v7 | 姿态、位置、混控解算 | ① PX4 入门、⑥ FanciSwarm |
| **中间件** | uORB（PX4）/ 函数调用（Mcontroller） | 模块间数据流 | ③ uORB 学习 |
| **数据层** | param / DataManager / ModuleParams / 日志 | 参数与航点存取 | ④ 飞行日志学习 |
| **系统层** | NuttX / FreeRTOS | 实时多任务调度 | ② Nuttx 知识 |
| **驱动层** | 字符设备 / HAL / SPI / I2C | 传感器与执行器 | ② 驱动入门、⑥ 传感器 |

## 四、两条飞控主线

| 维度 | PX4（学习/仿真主战场） | Mcontroller-v7（FanciSwarm 真机） |
| --- | --- | --- |
| RTOS | NuttX | FreeRTOS |
| 消息机制 | uORB 发布/订阅 | 直接函数调用 + MAVLink |
| 模块系统 | 独立模块动态加载 | 编译时静态链接 |
| 核心库 | 全部开源 | `libMcontroller-v7-FanciSwarm.a`（闭源） |
| ROS 通信 | 经 MAVROS | 同样经 MAVROS（都走 MAVLink） |

> 学习策略：**用 PX4 学架构与源码**（开源、资料全），**用 Mcontroller 做真机落地**（FanciSwarm 集群无人机）。两者在 ROS/MAVROS 层面对你透明。

---

## 五、学习路线要点

1. **先懂架构分层，再读代码** —— 知道「谁调用谁」，否则一头扎进某个 `.cpp` 会迷路。
2. **uORB 是主线索引** —— PX4 模块靠 uORB 解耦，搞清楚数据流就读懂了 80%。
3. **沿「控制主链路」读** —— 从「飞机怎么动起来」这条主线切入，而非从 `main()` 硬啃。
4. **闭源库只学接口** —— Mcontroller 的 EKF/PID/混控在 `.a` 里，学的是**架构、流程、状态机与调用方式**。
5. **仿真先行，真机兜底** —— Gazebo/SITL 验证逻辑，真机飞行看日志（`飞行日志` 对排障至关重要）。
