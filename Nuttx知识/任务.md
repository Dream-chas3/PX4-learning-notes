## 一、任务基础

### 1.1 什么是任务

NuttX 是**固定地址操作系统**，不支持"标准"进程概念。其调度的基本单元是**任务（Task）**——在同一地址空间中具有一定独立性的执行单元。

```

│                   操作系统四大模块                  │

│   │  ★ 本章   │  │          │  │          │      │
│   └──────────┘  └──────────┘  └──────────┘      │
│                 ┌──────────┐                      │
│                 │  I/O系统  │                      │
│                 └──────────┘                      │
└──────────────────────────────────────────────────┘
```

### 1.2 任务调度方式

| 调度方式 | 原理 | 特点 |
|----------|------|------|
| **时间片轮转** | 每个任务分配固定时间片，用完让出 CPU | 公平，但无优先级概念 |
| **基于优先级（抢占式）** ⭐ | 高优先级任务可随时打断低优先级任务 | **实时 OS 与 非实时 OS 的根本区别** |

> NuttX 是实时操作系统，默认采用**基于优先级的抢占式调度**；同优先级任务按 **SCHED_FIFO（先入先出）** 运行。

### 1.3 任务三态模型

```
       ┌─────────┐
       │   执行   │ ← 当前正在 CPU 上运行
       └────┬────┘
            │
    ┌───────┼───────┐
    ▼       │       ▼
┌──────┐   │   ┌──────┐
│  就绪  │   │   │  阻塞  │
│      │   │   │      │
│ 等待  │   │   │ 等待  │
│ CPU   │   │   │ 资源  │
│ 调度  │   │   │      │
└──┬───┘   │   └──┬───┘
   │       │      │
   └───────┼──────┘
           ▼
     资源就绪 → 就绪态
```

| 状态 | 含义 |
|------|------|
| **执行（Running）** | 任务正在 CPU 上运行 |
| **就绪（Ready）** | 满足所有条件，只等 CPU 空闲 |
| **阻塞（Blocked）** | 等待 CPU 之外的资源（如 I/O），即使 CPU 空闲也无法运行 |
| **延迟（特殊阻塞）** | 主动放弃 CPU，等待指定时间（不需获取资源） |

### 1.4 任务上下文与堆栈

> **任务上下文** = CPU 寄存器值 + 函数调用参数/局部变量 + 定时信息 + 文件描述符列表 + ...

- 所有上下文信息保存在**任务堆栈**中
- 创建任务时必须**指定堆栈大小**，创建后**不可更改**
- 递归调用多或局部变量大的任务 → 需分配**较大堆栈**
- 通过 `top` 命令观察堆栈实际使用量来调整

## 二、编程接口

### 2.1 任务创建

#### 函数原型

```c
#include <px4_platform_common/tasks.h>

px4_task_t px4_task_spawn_cmd(
    const char *name,       // (1) 任务名称
    int scheduler,          // (2) 调度策略
    int priority,           // (3) 任务优先级
    int stack_size,         // (4) 堆栈大小（字节）
    px4_main_t entry,       // (5) 任务入口函数指针
    char * const argv[]     // (6) 传递给入口函数的参数
);
```

| 参数 | 说明 |
|------|------|
| **(1) name** | 任务名字符串，便于识别 |
| **(2) scheduler** | `SCHED_FIFO`（先入先出）、`SCHED_RR`（时间片轮转）、`SCHED_DEFAULT`（=SCHED_RR） |
| **(3) priority** | ⚠️ **数值越大优先级越高**（与 Linux/VxWorks 相反！） |
| **(4) stack_size** | 堆栈大小（字节），初始给大些，用 `top` 调优，应超过最大值 10%~15% |
| **(5) entry** | `typedef int (*px4_main_t)(int argc, char *argv[])` |
| **(6) argv** | 参数数组，以空指针结尾；不需参数则直接为空 |

#### 优先级宏定义

| 宏 | 含义 |
|----|------|
| `SCHED_PRIORITY_MAX` | 最高优先级 |
| `SCHED_PRIORITY_DEFAULT` | 默认优先级 |
| `SCHED_PRIORITY_MIN` | 最低优先级 |

> 通常使用这些宏的**相对值**来定义任务优先级，如 `SCHED_PRIORITY_MIN + 5`

#### 返回值

- **正常**：非零任务 ID（PID），是任务的唯一标识
- **错误**：对应错误码

> 任务创建后**立即**开始与其他任务竞争 CPU。

#### 两种任务执行模式

```c
// 模式一：执行到底退出（用于资源初始化、命令响应等）
void task_func(void *para)
{
    /* 任务执行代码 */
    // 执行完毕自动退出
}

// 模式二：无限循环（更常见，只要不断电就一直运行）
void task_func(void *para)
{
    /* 初始化代码 */
    while (true)
    {
        /* 任务循环代码 */
    }
}
```

### 2.2 任务延时

延时期间任务**主动让出 CPU**，退出调度队列，低优先级任务获得执行机会。

```c
#include <px4_platform_common/time.h>

int px4_usleep(useconds_t usec);   // 微秒级延时
unsigned int px4_sleep(unsigned int seconds);  // 秒级延时
```

> 💡 `px4_usleep(0)` / `px4_sleep(0)`：在非 SCHED_RR 策略下，主动给同优先级任务一次运行机会。

### 2.3 任务管理函数

| 函数 | 功能 | 注意事项 |
|------|------|----------|
| `px4_task_delete(pid)` | 删除任务，释放堆栈 | ⚠️ 被删任务持有的资源（如已分配内存）可能无法使用 |
| `px4_task_exit(ret)` | 任务退出，释放堆栈、关闭文件描述符、刷新文件流 | 一般不需主动调用，任务执行完自动隐式调用 |
| `px4_show_tasks()` | 显示系统正在运行的任务信息 | 调试用；更常用 `top` 命令替代（仿真不支持 top） |
| `px4_task_is_running(name)` | 判断指定名称的任务是否正在执行 | 返回 `bool` |
| `px4_get_taskname()` | 获取当前任务的任务名 | 返回 `const char *` |

## 三、完整示例：后台可管理任务

### 3.1 与之前 "Hello Sky!" 的对比

| 问题 | 旧版 | 新版 |
|------|------|------|
| 占用 NSH 终端 | ❌ 运行时不能输命令 | ✅ 后台运行，不影响 NSH |
| 任务休眠 | ❌ 无休眠，低优先级任务饿死 | ✅ 延时让出 CPU |
| 任务管理 | ❌ 无法查询/停止 | ✅ start/status/stop 完整管理 |
| 重复启动保护 | ❌ 无 | ✅ 检测 `is_running()` |

### 3.2 完整源码（带注释）

```cpp
#include <string.h>
#include <px4_log.h>
#include <px4_platform_common/tasks.h>
#include <drivers/drv_hrt.h>       // 高精度计时器，已包含 time.h
using namespace time_literals;     // 启用 1_s、1_ms、1_us 字面量

extern "C" __EXPORT int test_app_main(int argc, char *argv[]);

// ── 全局状态变量 ──
static px4_task_t task_id = -1;         // 任务 ID，-1 表示未运行
static bool _task_should_exit = false;  // 退出标志

// ── 状态判断 ──
bool is_running()
{
    return task_id != -1;               // 靠任务 ID 判断运行状态
}

// ── 实际执行函数（无限循环模式） ──
void run()
{
    PX4_INFO("Hello Sky!");
    while (!_task_should_exit)
    {
        hrt_abstime now = hrt_absolute_time();    // 获取系统运行时间（μs）
        PX4_INFO("PX4 running time is %u (s).",
                 (unsigned int)(now / 1_s));
        hrt_abstime time_count = hrt_elapsed_time(&now); // 计算已用时间
        px4_usleep(1_s - time_count);            // 精确控制循环周期为 1s
    }
}

// ── 入口跳板函数 ──
int run_trampoline(int argc, char *argv[])
{
    _task_should_exit = false;
    run();
    return PX4_OK;
}

// ── 任务创建 ──
int task_spawn(int argc, char *argv[])
{
    task_id = px4_task_spawn_cmd(
        "test_app",
        SCHED_DEFAULT,                      // 默认调度策略（SCHED_RR）
        SCHED_PRIORITY_MIN + 5,              // 较低优先级，不影响其他任务
        1024,                                // 堆栈 1KB（简单任务够用）
        (px4_main_t)&run_trampoline,
        (char *const *)argv
    );
    if (task_id < 0)
    {
        task_id = -1;
        return -1;
    }
    return 0;
}

// ── start 命令 ──
int start_command_base(int argc, char *argv[])
{
    int ret = 0;
    if (is_running())
    {
        ret = -1;
        PX4_INFO("Task already running!");      // 防重复创建
    }
    else
    {
        ret = task_spawn(argc, argv);
        if (ret < 0)
            PX4_ERR("Task start failed (%i)", ret);
    }
    return ret;
}

// ── status 命令 ──
int status_command()
{
    if (is_running())
        PX4_INFO("app is running!");
    else
        PX4_INFO("app is not running!");
    return 0;
}

// ── stop 命令 ──
int stop_command()
{
    _task_should_exit = true;     // 设置退出标志 → 循环结束
    px4_sleep(2);                 // 等待 2s 让任务安全退出
    task_id = -1;                 // 重置任务 ID
    PX4_INFO("app stopped!");
    return 0;
}

// ── 主入口（命令分发） ──
int test_app_main(int argc, char *argv[])
{
    if (argc <= 1 || strcmp(argv[1], "-h") == 0
        || strcmp(argv[1], "help") == 0)
        return print_usage();

    if (strcmp(argv[1], "start") == 0)
        return start_command_base(argc - 1, argv + 1);

    if (strcmp(argv[1], "status") == 0)
        return status_command();

    if (strcmp(argv[1], "stop") == 0)
        return stop_command();

    return custom_command(argc - 1, argv + 1);
}
```

### 3.3 运行时 NSH 交互

```

INFO  [test_app] Hello Sky!
INFO  [test_app] PX4 running time is 1234 (s).
      # ← 随时可按回车输入新命令！
```

## 四、核心知识速查

| 知识点 | 要点 |
|--------|------|
| **调度单元** | 任务（Task），非进程 |
| **调度策略** | 基于优先级抢占 + 同优先级 FIFO/RR |
| **优先级方向** | ⚠️ **数值越大优先级越高**（与 Linux 相反） |
| **堆栈** | 创建时指定、不可更改、用 `top` 调优、预留 10%~15% |
| **后台运行** | `px4_task_spawn_cmd` 创建，不占用 NSH |
| **延时方式** | `px4_usleep()` / `px4_sleep()`，主动让出 CPU |
| **精确周期** | `hrt_absolute_time()` + `hrt_elapsed_time()` + 延时补偿 |
| **停止机制** | 退出标志 `_task_should_exit` → 跳出循环 |
| **防重复启动** | 用 `task_id != -1` 判断是否已在运行 |
