# 配置参数存取：param 系统

## 概述

PX4 的**参数系统（param）** 用于存储和访问飞行器的配置参数。参数值可以在 QGroundControl 中修改，也可以在代码中通过 `param_find` / `param_get` / `param_set` API 读写。

## 参数定义：test_app_param.c

```c
PARAM_DEFINE_INT32(TEST_APP_INT, 1);     // 整数参数，默认值 1
PARAM_DEFINE_FLOAT(TEST_APP_FLOAT, 0.1); // 浮点参数，默认值 0.1
```

`PARAM_DEFINE_INT32` 和 `PARAM_DEFINE_FLOAT` **不是 C 预处理宏**，而是被 PX4 的 Python 工具 `px_process_params.py` 静态扫描的标记字符串。

### 构建流程

```
src/*params.c → px_process_params.py → parameters.xml → px4_parameters.hpp → 编译进固件
```

cmake 自动 glob `*params.c` 和 `*parameters.c` 文件，无需在 CMakeLists 中显式列出。

> ⚠️ 改了 params.c 后若参数未生效：删 `build/*/parameters.xml` 重编。

---

## 核心 API

```cpp
#include <lib/parameters/param.h>

param_t param_find(const char *name);           // 按名称查找，返回句柄
int     param_get(param_t handle, void *val);    // 读取参数值
int     param_set(param_t handle, void *val);    // 设置参数值（自动写入 Flash）
```

## 读取 + 修改整数参数

```cpp
int32_t value_int;
param_t param = param_find("TEST_APP_INT");   // 查找句柄
param_get(param, &value_int);                  // 读取当前值 → 1（默认值）
PX4_INFO("old int value = %d", value_int);

value_int = 5;
param_set(param, &value_int);                  // 写入新值到 Flash
PX4_INFO("new int value = %d", value_int);
```

## 读取浮点参数

```cpp
float value_float = 0.0f;
param = param_find("TEST_APP_FLOAT");
param_get(param, &value_float);
PX4_INFO("float value = %.2f", (double)value_float);
```

## 监听参数更新

```cpp
#include <uORB/Subscription.hpp>
#include <uORB/topics/parameter_update.h>

uORB::Subscription parameter_update_sub{ORB_ID(parameter_update)};

while (!should_exit()) {
    if (parameter_update_sub.updated()) {
        param_get(param, &value_float);       // 重新读取最新值
        PX4_INFO("float value = %.2f", (double)value_float);
    }
    px4_sleep(1);
}
```

## 命令行操作

```bash
param list                  # 列出所有参数
param show TEST_APP_INT     # 查看参数值
param set TEST_APP_INT 10   # 修改参数
```

## 数据类型对照

| 参数类型宏 | C 变量类型 |
|-----------|-----------|
| `PARAM_DEFINE_INT32` | `int32_t` |
| `PARAM_DEFINE_FLOAT` | `float` |
| `PARAM_DEFINE_INT64` | `int64_t` |
| `PARAM_DEFINE_BOOL` | `int32_t` |

## 关键知识点

| 概念 | 说明 |
|------|------|
| `param_find(name)` | 查找参数，失败返回 `PARAM_INVALID` (65535) |
| `param_get(handle, &var)` | 读值，变量类型必须匹配参数类型 |
| `param_set(handle, &var)` | 写值，自动写入 Flash |
| `parameter_update` | uORB 主题，参数变更时推送通知 |
| params.c 文件 | 命名需匹配 `*params.c`，cmake 自动 glob |
