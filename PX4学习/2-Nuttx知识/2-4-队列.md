# 队列：PX4 工作队列（Work Queue）的使用

## 概述

本示例演示了 PX4 的**工作队列（Work Queue）**机制。与前两个例子（信号量、pthread）不同，这次不需要手动创建任务或线程，而是通过**继承 `px4::ScheduledWorkItem`** 将任务注册到 PX4 的工作队列中，由系统自动按固定周期调度执行。这是 PX4 中最标准的模块写法。

## C++ 基础速览

### `::` vs `:`

```cpp
// :: 作用域解析：谁里面的什么
px4::ScheduledWorkItem   // px4 命名空间里的类
TestApp::init()          // TestApp 类里的方法

// : 单冒号出现在两个场景
class TestApp : public ModuleBase<TestApp>  // [A] 继承
TestApp() : ScheduledWorkItem(MODULE, ...)  // [B] 初始化列表：先调父类构造
```

### `TestApp *instance` 指针

```cpp
TestApp *p = new TestApp();  // 堆上分配，p 存地址
p->init();                    // 通过指针调成员函数，等价于 (*p).init()
```

---

## 头文件

```cpp
class TestApp : public ModuleBase<TestApp>, public px4::ScheduledWorkItem {
public:
    TestApp();
    static int task_spawn(int argc, char *argv[]);
    static TestApp *instantiate(int argc, char *argv[]);
    void Run() override;   // 工作队列回调：每次调度执行
    void init();           // 注册到工作队列
};
```

### 继承关系

```
ModuleBase<TestApp>       px4::ScheduledWorkItem
   ↑                            ↑
   命令分发(main)               工作队列调度(ScheduleOnInterval, Run)
   _object, _task_id
   └──────────┬─────────────────┘
              │
          TestApp
```

---

## 核心实现

### 构造函数：传入工作队列配置

```cpp
TestApp::TestApp() : px4::ScheduledWorkItem(MODULE_NAME, px4::wq_configurations::test1) {}
//                  ↑ 在进入 { } 之前先调用父类构造函数
//                    参数1: 模块名
//                    参数2: 工作队列配置（预定义的 test1 队列）
```

### init()：注册周期回调

```cpp
void TestApp::init()
{
    ScheduleOnInterval(5000000, 5000000);
    //              ↑         ↑
    //          初始延迟     周期（纳秒），5000000ns = 5ms
}
```

### Run()：每次调度执行

```cpp
void TestApp::Run()
{
    PX4_INFO("This is a PX4 work queue test app!");
}
```

## 完整执行流程

```
用户输入: test_app start
    ↓
test_app_main → TestApp::main() → start_command_base() → task_spawn()
    ↓
px4_task_spawn_cmd → run_trampoline() (ModuleBase 提供)
    ↓
instantiate() → new TestApp()  →  构造函数自动注册到 wq_configurations::test1
    ↓
init() → ScheduleOnInterval(5ms, 5ms)
    ↓
┌──────────────────────────────────────────┐
│  PX4 工作队列管理器                       │
│  每 5ms 自动调用一次 TestApp::Run()       │
│  直到 test_app stop                      │
└──────────────────────────────────────────┘
```

## 关键知识点

| 概念 | 说明 |
|------|------|
| `ScheduledWorkItem` | PX4 工作队列基类，提供周期调度能力 |
| `ScheduleOnInterval(a, b)` | 注册周期回调：延迟 a ns，之后每 b ns 执行一次 |
| `Run()` override | 纯虚函数，必须实现，每次调度时被调用 |
| `ModuleBase<T>` | CRTP 模式，自动提供 main() 命令分发 |
| 构造函数初始化列表 | `TestApp() : 父类(参数) { }` 先构造父类再进函数体 |
