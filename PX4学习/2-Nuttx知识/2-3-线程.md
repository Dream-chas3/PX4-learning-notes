# 线程：pthread 创建与条件变量同步

## 概述

本示例演示了在 **PX4 POSIX 平台**下，使用 **POSIX 线程（pthread）** 进行多线程编程。主任务内部通过 `pthread_create` 创建两个线程，并通过**条件变量**实现线程间的通知同步：线程1每隔 1 秒广播通知，线程2阻塞等待通知后被唤醒。与信号量例子不同，本例不再使用 PX4 任务 API，而是直接在任务内部使用标准 pthread。

## 全局资源

```cpp
pthread_mutex_t mutex = PTHREAD_MUTEX_INITIALIZER;
pthread_cond_t cond   = PTHREAD_COND_INITIALIZER;
```

> 静态初始化宏用于编译期初始化，等价于 `pthread_mutex_init(&mutex, NULL)` 等运行时调用，但更简洁、无失败风险。

## 线程1：定时通知者

```cpp
void *thread_loop1(void *arg)
{
    px4_prctl(PR_SET_NAME, "test_thread1", px4_getpid());
    while (!_task_should_exit) {
        PX4_INFO("thread1 is running");
        pthread_cond_broadcast(&cond);   // 唤醒所有等待者
        px4_sleep(1);
    }
    return nullptr;
}
```

## 线程2：阻塞等待者

```cpp
void *thread_loop2(void *arg)
{
    px4_prctl(PR_SET_NAME, "test_thread2", px4_getpid());
    while (!_task_should_exit) {
        pthread_mutex_lock(&mutex);       // ① 加锁
        pthread_cond_wait(&cond, &mutex);  // ② 原子：解锁+阻塞+被唤醒后重加锁
        pthread_mutex_unlock(&mutex);      // ③ 解锁
        PX4_INFO("thread2 is running");    // ④ 被唤醒后执行
    }
    return nullptr;
}
```

### pthread_cond_wait 的原子操作

```
pthread_cond_wait(&cond, &mutex) 一次调用做了三件事：

① 解锁 mutex（让别的线程能拿到锁）
② 阻塞等待 cond 被 broadcast/signal
③ 被唤醒后重新加锁 mutex，然后返回
```

## 主逻辑：线程的创建与回收

```cpp
void run()
{
    pthread_t pth1, pth2;
    pthread_attr_t pth_attr;
    pthread_attr_init(&pth_attr);
    pthread_attr_setstacksize(&pth_attr, 1024);

    struct sched_param param;
    pthread_attr_getschedparam(&pth_attr, &param);
    param.sched_priority = SCHED_PRIORITY_MIN + 5;
    pthread_attr_setschedparam(&pth_attr, &param);

    pthread_create(&pth1, &pth_attr, thread_loop1, nullptr);
    pthread_create(&pth2, &pth_attr, thread_loop2, nullptr);

    pthread_join(pth1, nullptr);  // 阻塞等待线程1结束
    pthread_join(pth2, nullptr);  // 阻塞等待线程2结束
}
```

## 执行时序

```
线程1:  打印 → broadcast → sleep(1) → 打印 → broadcast → sleep(1) → ...
线程2:       wait被唤醒 → 解锁+打印 → wait阻塞 → 被唤醒 → 打印 → ...
```

## 架构：PX4 Task 与 pthread 的关系

```
test_app_main → task_spawn → PX4 Task "test_app"
                                  │
                    pthread_create ├── thread_loop1 (广播)
                                   └── thread_loop2 (等待)
```

## 关键知识点

| 概念 | 说明 |
|------|------|
| `pthread_create` | 创建新线程，非阻塞，立刻返回 |
| `pthread_join` | 阻塞等待线程结束，回收资源 |
| `pthread_cond_wait` | 原子地解锁 mutex 并阻塞，被唤醒后重新加锁 |
| `pthread_cond_broadcast` | 唤醒所有等待该条件变量的线程 |
| `pthread_cond_signal` | 只唤醒一个等待者 |
| `PTHREAD_MUTEX_INITIALIZER` | 互斥锁静态初始化宏 |
