# 自定义参数封装与常规使用方法

## 概述

在[[1-配置参数存取]]中使用了原始的 `param_find` / `param_get` / `param_set` C API 来读写参数。PX4 提供了更现代的 **C++ 封装方式**——通过继承 `ModuleParams` 基类，使用 `ParamInt` / `ParamFloat` 等模板类，自动管理参数缓存和更新同步。

## 两种方式对比

| | 原始 API | ModuleParams 封装 |
|---|---|---|
| **基类** | 仅 `ModuleBase` | `ModuleBase` + `ModuleParams` |
| **参数声明** | 无（运行时查找） | `DEFINE_PARAMETERS((ParamInt<T>)var)` |
| **读取值** | `param_find` + `param_get` | `var.get()` |
| **设置值** | `param_set` | `var.set(val)` + `var.commit()` |
| **参数更新检测** | 手动订阅 `parameter_update` | `updateParams()` 自动触发 |
| **类型安全** | 弱（传入错误类型编译不报错） | 强（模板编译期校验） |
| **性能** | 每次 `param_get` 走系统调用 | 缓存值直接读取 |

## 一、参数定义文件：test_app_params.c

```c
/**
 * test_app_float
 *
 * @min 0
 * @max 100
 * @decimal 2
 * @increment 0.01
 * @unit m
 * @group Test
 */
PARAM_DEFINE_FLOAT(TEST_APP_FLOAT, 0.1f);
```

### 注释标签速查

| 标签 | 含义 | 示例 |
|------|------|------|
| `@min` / `@max` | 最小/最大值 | `@min 0` |
| `@unit` | 单位 | `@unit m` |
| `@decimal` | 小数位数（float 专用） | `@decimal 2` |
| `@increment` | 步长（float 专用） | `@increment 0.01` |
| `@group` | QGC 中的分组名 | `@group Test` |

## 二、类声明：test_app_main.h

```cpp
#include <px4_platform_common/module_params.h>

class TestApp : public ModuleBase<TestApp>, public ModuleParams
{
public:
    TestApp();
    void run() override;

private:
    void parameters_update(bool force = false);

    DEFINE_PARAMETERS(
        (ParamInt<px4::params::TEST_APP_INT>) value_int,
        (ParamFloat<px4::params::TEST_APP_FLOAT>) value_float
    );
};
```

### 三重继承关系

```
ModuleBase<TestApp>          ModuleParams
   ↑                            ↑
   任务管理                     参数封装
   └──────────┬─────────────────┘
              │
           TestApp
```

### DEFINE_PARAMETERS 宏

自动展开为成员变量声明 + `updateParamsImpl()` 重写 + 参数初始化逻辑。

## 四、运行时读取参数值

```cpp
int32_t v = value_int.get();     // O(1) 缓存读取
float f   = value_float.get();   // 同上
```

## 五、参数更新检测

```cpp
void TestApp::parameters_update(bool force)
{
    bool params_updated = parameter_update_sub.updated();
    if (params_updated || force) {
        updateParams();  // 触发 updateParamsImpl()，同步所有 ParamInt/Float 缓存
    }
}
```

**更新链路**：
```
QGC 修改参数 → PX4 写入 Flash → 发布 parameter_update uORB
    → updated() 返回 true → updateParams()
    → updateParamsImpl() → 每个 ParamInt/Float::update() 刷新缓存
    → 下次 get() 拿到最新值
```

## 六、主循环：发布参数到 uORB

```cpp
void TestApp::run()
{
    uORB::Publication<debug_value_s> dbg_pub(ORB_ID(debug_value));
    debug_value_s dbg = {};

    while (!should_exit()) {
        parameters_update();
        dbg.timestamp = hrt_absolute_time();
        dbg.value = value_float.get();       // 读取缓存参数值
        dbg_pub.publish(dbg);                // 发布到 debug_value 主题
        px4_sleep(1);
    }
}
```

## 选用指南

```
需要参数？
   ├── 临时测试 → 原始 API（param_find + param_get）
   └── 生产模块 → ModuleParams 封装（类型安全、缓存加速）
```

## 关键知识点

| 概念 | 说明 |
|------|------|
| `ModuleParams` | 参数 C++ 封装基类 |
| `ParamInt<T>` / `ParamFloat<T>` | 参数模板类 |
| `DEFINE_PARAMETERS(...)` | 批量声明参数实例宏 |
| `value.get()` | 读取缓存参数值 |
| `value.set(val)` + `commit()` | 设置参数并写入 Flash |
| `updateParams()` | 触发所有参数缓存同步 |
