# 飞行任务参数存取：DataManager（dm_read）

## 概述

PX4 使用 **DataManager（dataman）** 模块在持久化存储（Flash/FRAM）中保存飞行任务的关键数据，包括**航点、地理围栏、安全点**。这些数据由 QGroundControl 上传后写入 dataman，飞行时 navigator 模块读取执行。

本示例演示如何通过 `dm_read()` 从 dataman 中逐条读取这些数据。

## 数据存储模型

```
┌──────────────────────────────────────────────────────┐
│                  DataManager (Flash/FRAM)             │
│                                                      │
│  DM_KEY_SAFE_POINTS     [0]=统计, [1..7]=安全点坐标   │
│  DM_KEY_FENCE_POINTS    [0]=统计, [1..63]=围栏顶点    │
│  DM_KEY_WAYPOINTS_0     [0..N]=航点数据               │
│  DM_KEY_WAYPOINTS_1     [0..N]=航点数据(交替缓冲)      │
│  DM_KEY_MISSION_STATE   [0]=任务全局状态               │
└──────────────────────────────────────────────────────┘

每个键(key)下有多条记录(index)，索引 0 固定存统计信息。
```

## 关键 API：`dm_read()`

```cpp
ssize_t dm_read(
    dm_item_t item,    // 数据类别
    unsigned index,    // 第几条（0=统计信息）
    void *buffer,      // 读取结果存放的缓冲区
    size_t buflen      // sizeof(结构体)
);
```

### dm_item_t 枚举

```cpp
typedef enum {
    DM_KEY_SAFE_POINTS = 0,     // 安全点
    DM_KEY_FENCE_POINTS,        // 地理围栏顶点
    DM_KEY_WAYPOINTS_OFFBOARD_0,// 航点缓冲区0
    DM_KEY_WAYPOINTS_OFFBOARD_1,// 航点缓冲区1（双缓冲交替写）
    DM_KEY_MISSION_STATE,       // 任务全局状态
} dm_item_t;
```

---

## 一、读取航点（Waypoints）

```cpp
// 第1步：读任务全局状态 → 获取航点总数
struct mission_s mission;
dm_read(DM_KEY_MISSION_STATE, 0, &mission, sizeof(mission_s));
// mission.count = 总航点数
// mission.dataman_id = 实际存储 key（WAYPOINTS_0 或 _1）

// 第2步：逐个读取每个航点
struct mission_item_s item[mission.count];
for (unsigned i = 0; i < mission.count; i++) {
    dm_read((dm_item_t)mission.dataman_id, i, &item[i],
            sizeof(struct mission_item_s));
    PX4_INFO("mission #%d cmd ID is %d", i, item[i].nav_cmd);
}
```

> `mission.dataman_id` 记录了实际使用的缓冲区（双缓冲机制），必须强转为 `dm_item_t`。

## 二、读取地理围栏（Geofence）

```cpp
struct mission_stats_entry_s stats;
dm_read(DM_KEY_FENCE_POINTS, 0, &stats, sizeof(mission_stats_entry_s));

struct mission_fence_point_s fence_point;
for (unsigned i = 1; i < stats.num_items; ++i) {   // 索引从1开始！
    dm_read(DM_KEY_FENCE_POINTS, i, &fence_point, sizeof(mission_fence_point_s));
    PX4_INFO("Geofence point #%d position is (%f, %f)", i, fence_point.lon, fence_point.lat);
}
```

## 三、读取安全点（Safe Points）

```cpp
dm_read(DM_KEY_SAFE_POINTS, 0, &stats, sizeof(mission_stats_entry_s));

struct mission_safe_point_s safe_point;
for (unsigned i = 1; i < stats.num_items; ++i) {   // 索引从1开始！
    dm_read(DM_KEY_SAFE_POINTS, i, &safe_point, sizeof(mission_safe_point_s));
    PX4_INFO("Safepoint #%d position is (%f, %f)", i, safe_point.lon, safe_point.lat);
}
```

## 索引起始区别

| 数据类型 | 统计信息位置 | 实际条目从哪开始 |
|----------|------------|----------------|
| 航点 | 单独的 `DM_KEY_MISSION_STATE` | index 0 |
| 围栏 | `DM_KEY_FENCE_POINTS[0]` | index 1 |
| 安全点 | `DM_KEY_SAFE_POINTS[0]` | index 1 |

## 常用 cmd ID 速查

| ID | 指令 | 含义 |
|----|------|------|
| 16 | `NAV_CMD_WAYPOINT` | 普通航点 |
| 21 | `NAV_CMD_LAND` | 着陆 |
| 22 | `NAV_CMD_TAKEOFF` | 起飞 |
| 178 | `MAV_CMD_DO_CHANGE_SPEED` | 修改巡航速度 |

## 完整数据流

```
QGC Plan页面 → MAVLink上传 → commander/dm_write → DataManager(Flash)
                                                        ↓
                                              dm_read（本示例读取）
```
