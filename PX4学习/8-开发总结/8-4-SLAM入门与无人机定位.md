# SLAM 入门与无人机定位

> 来源：ChatGPT 对话扩展
> 主题：SLAM 是什么、为什么无人机需要它、在系统中的位置、与 GPS/UWB 的区别

---

## 一、SLAM 是什么

**SLAM** = **S**imultaneous **L**ocalization **A**nd **M**apping

中文：**同时定位与建图**

### 拆开理解

| 英文 | 中文 | 回答的问题 |
|------|------|-----------|
| **Localization** | 定位 | "我在哪里？"（x=3m, y=5m, z=2m） |
| **Mapping** | 建图 | "周围环境什么样？"（房间布局、障碍物位置） |

### 一句话总结

> 无人机**一边建立环境地图，一边根据地图判断自己的位置**。

```
无人机飞过一个房间：

    +-------------+
    |             |
    |    🛸       |    ← 无人机在飞行
    |             |
    |       🚪    |
    +-------------+

SLAM 同时做两件事：
  1. 画出这个房间的地图（Mapping）
  2. 一直知道无人机在地图里的位置（Localization）
```

## 二、为什么无人机需要 SLAM？

### 问题：无人机怎么知道自己在哪里？

PX4 飞控有 IMU（加速度计 + 陀螺仪），可以通过积分推算位置：

```
加速度 → 积分 → 速度 → 积分 → 位置
```

**但误差会累积**：

| 飞行距离 | IMU 推算 | 真实位置 | 误差 |
|----------|----------|----------|------|
| 10 米 | 10.8 米 | 10 米 | 0.8 米 |
| 100 米 | 可能差几十米 | 100 米 | 不可接受 |

### 各种定位方案对比

| 方案 | 环境 | 设备 | 优点 | 缺点 |
|------|------|------|------|------|
| **GPS** | 室外 | GPS 模块 | 简单 | 室内无信号 |
| **UWB** | 室内 | 4 个基站 + 标签 | 精度高（<10cm） | 需要架设基站 |
| **SLAM** | 室内/室外 | 摄像头或激光雷达 | 不需外部设备 | 算法复杂 |

## 三、SLAM 的类型

### 视觉 SLAM

使用摄像头：

```
摄像头 → 图像 → SLAM 算法 → 位置 + 地图
```

常见方案：

| 算法 | 传感器 | 特点 |
|------|--------|------|
| ORB-SLAM3 | 单目/双目/RGB-D 相机 | 经典方案，广泛使用 |
| VINS-Fusion | 单目 + IMU | 视觉惯性融合 |
| RTAB-Map | RGB-D 相机 | 实时建图 |

硬件示例：Intel RealSense 深度相机

### 激光 SLAM

使用激光雷达：

```
LiDAR → 距离点云 → SLAM → 地图
```

常见方案：Cartographer（Google）、LOAM 系列

## 四、SLAM 在无人机系统中的位置

### 完整架构

```
       摄像头 / LiDAR
            ↓
       树莓派（伴随计算机）
            ↓
       SLAM 算法（ORB-SLAM3 / VINS-Fusion）
            ↓
       得到无人机位置（vision_pose）
            ↓
       ROS Topic
            ↓
       MAVROS（/mavros/vision_pose/pose）
            ↓
       MAVLink
            ↓
       PX4 飞控
            ↓
       位置控制 / 飞行
```

### 数据流

```
摄像头图像
    → SLAM 计算位置（x, y, z, 姿态）
    → 发布 /vision_pose ROS Topic
    → MAVROS 转发到 /mavros/vision_pose/pose
    → PX4 接收视觉定位
    → 可以做位置控制、定点悬停、自主导航
```

## 五、SLAM 和你学习路线的关联

### 你现在在学什么

```
PX4 源码 → uORB → MAVLink → MAVROS → ROS Node → Offboard 控制
```

### SLAM 在整个自主无人机体系中的位置

```
        SLAM（定位）
           ↓
       位置信息
           ↓
   ROS 规划算法（路径规划）
           ↓
       目标位置
           ↓
       MAVROS
           ↓
       PX4（飞行控制）
           ↓
        飞行
```

三层分工：

| 层 | 负责 | 回答的问题 |
|----|------|-----------|
| **PX4** | 稳定飞行 | "怎么飞稳？" |
| **定位系统**（SLAM/GPS/UWB） | 位置感知 | "我在哪里？" |
| **ROS** | 任务决策 | "我要去哪里？" |
| **规划算法** | 路径生成 | "怎么过去？" |

## 六、你现在需要学 SLAM 吗？

### 建议顺序

| 阶段 | 内容 | 状态 |
|------|------|------|
| **阶段 1（当前）** | ROS + MAVROS + Offboard 控制，Gazebo 仿真飞起来 | ⏳ 进行中 |
| **阶段 2** | 学习各种定位来源：GPS、UWB、VIO、SLAM | 🔜 之后 |
| **阶段 3** | 自主导航：SLAM + 路径规划 + 避障 | 🔜 之后 |

> 💡 先把 MAVROS + Offboard 控制链路打通，再学 SLAM 会非常顺畅，因为 SLAM 只是"定位信息"的一个来源，对 ROS 和 PX4 来说，不管是 GPS 还是 SLAM 给的坐标，处理方式都是一样的。

## 七、扩展知识

### 7.1 VIO 是什么

**VIO** = Visual-Inertial Odometry（视觉惯性里程计）

= 视觉 SLAM + IMU 紧耦合

比纯视觉 SLAM 更鲁棒，是无人机上最常用的视觉定位方案之一。

### 7.2 SLAM 的关键概念

| 概念 | 含义 |
|------|------|
| **特征点** | 图像中的角点/边缘，用于匹配相邻帧 |
| **回环检测** | 识别出"我以前来过这里"，修正累积误差 |
| **关键帧** | 选出有代表性的图像帧，减少计算量 |
| **位姿图优化** | 用图模型全局优化轨迹 |

### 7.3 FanciSwarm 与 SLAM

FanciSwarm 树莓派套件的设计目标之一就是运行视觉算法。树莓派有了摄像头 + SLAM，无人机就能在无 GPS 无 UWB 的室内环境中自主定位和飞行。这也是为什么它的高级开发案例包含 YOLO 目标检测和 Aruco 码视觉引导——这些和 SLAM 是同一套视觉体系的不同应用。
