# 光流传感器（LC302）

> 光流传感器利用**图像帧间位移**估计飞机的水平速度，用于**室内/无 GNSS 环境下的水平定位**。LC302 是基于 PMW3901 光流芯片的模块（原理类似光学鼠标）。

## 一、原理介绍

### 1.1 光流原理

光流（Optical Flow）指**图像中像素的运动**。当飞机移动时，下视摄像头拍摄的地面纹理随之移动，通过对比连续两帧图像，可以算出像素位移：

```
光流速度 = 像素位移 / 帧间隔
地面速度 = 光流速度 × (高度 / 焦距)  ← 需要知道飞行高度
```

**关键**：光流测的是"像素/秒"，要换算成"米/秒"必须知道**离地高度**（所以光流通常配合激光测距/气压计使用）。

### 1.2 PMW3901 芯片原理

PMW3901（PixArt）是光学鼠标传感器芯片，内部：
- 小摄像头（约 30×30 像素）+ 红外照明
- 内置图像处理器，**直接输出 X/Y 方向位移**（累加值），无需外部做图像处理

LC302 模块在 PMW3901 基础上加了 MCU 和串口，输出标准协议帧。

## 二、硬件接口

LC302 挂在 **UART** 上，config.h 里 `COMM_2 = LC302_COMM`：

```
串口2（UART，19200 波特率）──► LC302 光流模块
```

config.h 相关配置：

```c
#define COMM_2 LC302_COMM        // 串口2 配置为光流模式
#define COMM_2_BANDRATE 19200    // 波特率 19200
#define USE_FLOW 1               // 使能光流
```

## 三、数据结构

`hal.h` 中定义（这是光流协议帧的解析结果）：

```c
typedef struct {
    int16_t  flow_x_integral;    // X 方向位移积分（累计像素）
    int16_t  flow_y_integral;    // Y 方向位移积分
    uint16_t integration_timespan;// 积分时间间隔（采样周期）
    uint16_t ground_distance;    // 离地距离（配合测距）
    uint8_t  quality;            // 质量/置信度（纹理是否有效）
    uint8_t  version;            // 协议版本
} LC302_Data;
```

> [!tip] 位移积分 → 速度
> `flow_x_integral / integration_timespan` 得到 X 方向像素速度，再乘以高度标定系数 → 地面速度。`ground_distance` 字段表明模块内部集成了测距或由外部提供高度。

## 四、驱动代码解读

### 4.1 驱动函数（hal.h 声明）

```c
uint8_t get_lc302_data(uint8_t buf);  // 解析光流数据（逐字节喂入）
                                      // 返回 0:解析成功 1:未解析完 2:解析失败
void opticalflow_update(void);        // 光流更新（速度换算）
```

### 4.2 调用流程

**数据解析**：光流挂在 COMM_2（串口2），数据通过串口中断回调进入解析器。

在 [Loop50hzTask](Core/Src/freertos.c#L438-L457) 中更新：

```cpp
void Loop50hzTask(void *argument){
    // ...
    vl53lxx_update();
    get_i2c_tf2mini_data();  // 测距数据（光流需要高度）
    // ...
}
```

光流的 `opticalflow_update()` 由系统在串口收到数据时驱动（闭源实现）。

### 4.3 数据结构中的状态

`common.h` 定义了光流状态：

```c
typedef struct {
    bool healthy;          // 光流数据是否健康
    float flow_dt;         // 采样间隔
    uint32_t last_healthy_ms;
    Vector2f rads;         // 角度
    Vector2f vel;          // 速度
    Vector2f pos;          // 位置（积分）
} Opticalflow_state;
extern Opticalflow_state opticalflow_state;
```

## 六、应用场景

| 场景 | 说明 |
|---|---|
| **室内定高** | 光流 + 激光测距 → 无 GNSS 的水平定位 |
| **定点悬停** | 光流提供 XY 速度 → 位置环 |
| **GNSS 丢失备份** | GNSS 失效时用光流维持位置 |

## 七、要点总结

1. 光流是**室内定位**的重要传感器（GNSS 在室内不可用）
2. 原理类似光学鼠标，PMW3901 直接输出位移
3. **必须配合高度**（激光测距/气压计）才能换算成地面速度
4. 数据解析 `get_lc302_data` 的返回值设计（0/1/2）是串口协议解析的典型写法
5. `quality` 字段反映地面纹理质量，纹理差时光流不可用
