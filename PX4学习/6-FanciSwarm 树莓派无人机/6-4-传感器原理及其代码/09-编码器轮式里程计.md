# 编码器（轮式里程计）

> 编码器测量**轮子转动角度/速度**，是轮式机器人（麦克纳姆轮底盘、UGV）的**里程计（Odometry）**。本固件用它实现地面机器人的位置估计，对应 `EKF_Odometry`。

## 一、原理介绍

### 1.1 编码器原理

编码器检测电机/轮子的转动：

| 类型 | 原理 | 输出 |
|---|---|---|
| **增量式光电编码器** | 光电对射，光栅盘遮光 → 脉冲 | A/B 两相脉冲 |
| **霍尔编码器** | 磁钢 + 霍尔元件 → 脉冲 | A/B 两相脉冲 |

**正交编码**：A/B 两相相位差 90°，通过相位关系判断**方向**（正转/反转），通过脉冲数计算**转角**。

### 1.2 里程计原理

轮式里程计通过轮子转角推算机器人位移：

```
轮子转过角度 θ → 行走距离 s = θ × r（轮半径）
左轮距离 sL，右轮距离 sR
直行距离 = (sL + sR) / 2
转角 = (sR - sL) / 轮距
```

麦克纳姆轮底盘的 4 轮速度由独立编码器测量，解算出车体的 X/Y 平移和旋转。

## 二、硬件接口

编码器挂在 **GPIO 外部中断**上（`config.h` 里 `USE_ENCODER 0`，默认关闭）：

```
GPIO1/GPIO3/GPIO5/GPIO7 → 编码器中断（check_wheel_count_gpio1/3/5/7）
```

中断回调在 [freertos.c](Core/Src/freertos.c#L745-L783)：

```cpp
void gpio1_interrupt_callback(void){
#if USE_ENCODER
    check_wheel_count_gpio1();   // 编码器1计数
#endif
}
// gpio3/5/7 同理（对应 4 个轮子）
```

> [!note] 为什么是 GPIO 中断
> 编码器脉冲频率高（电机转速 × 编码器线数），用 GPIO 外部中断逐个脉冲计数。计数逻辑（方向判断、去抖）在闭源驱动里。

## 三、驱动函数（hal.h 声明）

```c
void encoder_init(void);                    // 编码器初始化
void check_wheel_count_gpio1(void);         // 轮1计数（中断回调）
void check_wheel_count_gpio3(void);
void check_wheel_count_gpio5(void);
void check_wheel_count_gpio7(void);
int32_t get_left_count(void);               // 左轮累计计数
int32_t get_right_count(void);              // 右轮累计计数
float get_left_theta(void);                 // 左轮转角（rad）
float get_right_theta(void);                // 右轮转角（rad）
```

## 四、调用流程

**初始化**（[freertos.c InitTask](Core/Src/freertos.c#L336-L338)）：

```cpp
#if USE_ENCODER
  encoder_init();
#endif
```

**中断计数**（[freertos.c](Core/Src/freertos.c#L745-L783)，GPIO 中断触发）：

```cpp
void gpio1_interrupt_callback(void){
#if USE_ENCODER
    check_wheel_count_gpio1();
#endif
}
```

**位置更新**（[freertos.c Loop400hzTask](Core/Src/freertos.c#L369)）：

```cpp
encoder_position_update();   // 400Hz 里程计位置更新
ekf_odom_xy();               // 里程计 XY 融合
```

## 五、数据流

```
编码器(GPIO中断) ──► check_wheel_count_gpioX() ──► get_left/right_count()
    ──► encoder_position_update() ──► 里程计位移 ──► EKF_Odometry ──► 位置
```

EKF_Odometry 对象（[maincontroller.cpp](Maincontroller/src/maincontroller.cpp#L116)）：

```cpp
EKF_Odometry *ekf_odometry = new EKF_Odometry(_dt, 0.0016, 0.0016, 0.000016, ...);
```

## 六、应用场景

| 场景 | 说明 |
|---|---|
| **麦克纳姆轮底盘** | mode_mecanum.cpp 轮式定位 |
| **UGV 模式** | 地面机器人里程计 |
| **室内定位** | 无 GNSS 时的轮式推算（配合 IMU） |

> [!note] 跨模态体现
> 编码器是 FanciSwarm **跨模态机器人**（飞行 + 地面）的体现：飞行用 IMU/GNSS/UWB，地面用编码器 + 麦克纳姆轮。同一套 `EKF_Odometry` 融合框架通吃。

## 七、要点总结

1. 编码器是**地面机器人**（麦克纳姆/UGV）的里程计，默认关闭（`USE_ENCODER 0`）
2. 用 GPIO 外部中断逐个脉冲计数，正交编码判方向
3. 计数 → 转角 → 位移 → `EKF_Odometry` 融合 → 位置
4. 体现飞控的**跨模态**设计：同一控制框架支持飞行和地面运动
