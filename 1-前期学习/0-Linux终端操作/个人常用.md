## 📋 我的常用指令

### 示例：快速创建一个新笔记

**命令**

```bash
touch ~/桌面/README/新笔记.md
```

- **说明**：在当前 Obsidian 仓库中创建一个空白 Markdown 文件
- **场景**：想快速新建笔记而不打开 Obsidian
- **注意**：文件名如果有空格需要加引号

---

### 示例：查看端口占用并释放

**命令**

```bash
sudo lsof -i :3000
kill -9 <PID>
```

- **说明**：查看谁占用了 3000 端口，然后杀掉该进程
- **场景**：启动开发服务器时提示端口被占用
- **注意**：⚠️ `kill -9` 是强制终止，先尝试 `kill <PID>` 优雅关闭

---

### 示例：Git 提交到新分支并推送

**命令**

```bash
git checkout -b feat/my-feature
git add .
git commit -m "feat: 添加新功能"
git push -u origin feat/my-feature
```

- **说明**：创建新分支 → 暂存所有变更 → 提交 → 推送并建立追踪
- **场景**：开始一个新功能开发
- **注意**：确认当前在正确的基准分支上再切新分支
