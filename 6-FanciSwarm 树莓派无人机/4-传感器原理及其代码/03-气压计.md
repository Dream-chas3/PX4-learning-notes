# 气压计（Barometer）

> 气压计测量大气压强，通过"气压随高度升高而降低"的物理规律，换算出**海拔高度**。是飞控**定高（AltHold）**的核心传感器，配合激光测距在低空获得更精确的高度。

## 一、原理介绍

### 1.1 气压测高原理

大气压强随高度按指数规律衰减，标准大气模型（ISA）给出换算公式：

```
P = P0 · (1 - L·h/T0)^(g·M/(R·L))
h = T0/L · [1 - (P/P0)^(R·L/(g·M))]
```

其中 P0=101325Pa（海平面气压），T0=288.15K，L=0.0065K/m。

**关键问题**：气压计测的是"相对高度"，需要知道基准面气压 P0。P0 随天气变化，所以起飞时要**归零**（把当前气压设为参考基准），之后测的高度就是相对起飞点的高度。

### 1.2 测量元件

气压计芯片 = **压阻式 MEMS 压力传感器** + **温度传感器** + ADC + 数字接口：

- **压阻式 MEMS**：硅膜片在气压下形变，膜片上的压敏电阻阻值变化（惠斯通电桥）→ 电压 → ADC → 数字气压值
- **温度补偿**：压敏电阻对温度敏感，必须测温度做补偿（芯片内部已做，但高端应用还会二次补偿）

### 1.3 本固件支持的型号

| 型号 | 厂商 | 特点 |
|---|---|---|
| **MS5611** | MEAS/TE | 经典飞控气压计，24bit ADC，0.1m 分辨率 |
| **MS5607** | MEAS/TE | MS5611 的低成本版，20bit ADC |
| **SPL06** | Infineon/歌尔 | 新一代，带内部温度补偿 |

## 二、硬件接口

气压计与 IMU 共用 **SPI1** 总线，通过独立的 `BARO_CS` 片选区分：

```
PA5 → SPI1_SCK, PA6 → SPI1_MISO, PA7 → SPI1_MOSI
BARO_CS → 片选（hal.h 的 BARO_CS_H/L 宏）
```

> [!note] 通信时序
> 这类气压计采用"**写命令 → 等待转换 → 读结果**"的流程。MS5611/SPL06 转换时间约几个 ms，通常用状态机或延时代码等待转换完成（实现在闭源驱动中）。

## 三、数据结构

`hal.h` 中定义：

```c
typedef struct {
    float temp;      // 温度 ℃
    float baro_alt;  // 气压高度 m
} MS5611_Data;

typedef struct {
    float temp;      // 温度 ℃
    float baro_alt;  // 气压高度 m
} MS5607_Data;

typedef struct {
    float temp;         // 温度 ℃
    float baro_alt;     // 气压高度 m
    float temp_init;    // 初始温度（基准）
    float baro_alt_init;// 初始高度（基准）
} SPL06_Data;
```

> 注意：`baro_alt` 是**已经换算好的高度**（单位 m），气压→高度的换算（含基准归零）在闭源驱动里完成。SPL06 额外保存了初始值，用于相对高度计算。

## 四、驱动代码解读

### 4.1 驱动函数（hal.h 声明）

```c
uint8_t BARO_Init(void);          // 初始化，返回 0 成功
void BARO_Get_Date(void);         // 读取气压数据
void Baro_set_press_offset(float vel);   // 设置气压偏移（速度修正）
void Baro_set_temp_offset_gain(float gain); // 温度偏移增益
```

### 4.2 调用流程

**初始化**（[freertos.c InitTask](Core/Src/freertos.c#L326)）：

```cpp
while(BARO_Init());   // 注意！while 循环直到初始化成功（失败会卡在这里）
```

**数据采集**（[freertos.c IMUTask](Core/Src/freertos.c#L624-L640)，500Hz）：

```cpp
void IMUTask(void *argument){
    vTaskDelayUntil(&PreviousWakeTime, TimeIncrement);  // 2ms
    IMU_Get_Data();
    BARO_Get_Date();   // 读气压计
}
```

### 4.3 数据流（气压高度 → EKF 融合）

```
BARO_Get_Date() ──► baro_alt ──► _baro_alt_filter(低通5Hz) ──► EKF_Baro ──► 高度
```

在 [Loop400hzTask](Core/Src/freertos.c#L366) 中：

```cpp
ahrs_update();
ekf_baro_alt();   // 气压高度 EKF 融合
```

EKF_Baro 对象初始化（[maincontroller.cpp](Maincontroller/src/maincontroller.cpp#L114)）：

```cpp
EKF_Baro *ekf_baro = new EKF_Baro(_dt, 0.01, 1.0, 0.000016, 0.000016);
//                                  dt   Q     R_pos R_vel  R_accel
```

> [!tip] 为什么要 EKF 融合
> 气压计高度**噪声大、有延迟、受气流/螺旋桨下洗影响**。EKF 把它和加速度计（垂直积分）融合，得到平滑、响应快的高度估计。这就是 `EKF_Baro` 的作用。

### 4.4 温度补偿

气压计对温度敏感，`baro_temp_offset_gain`（common.h 参数）用于二次温度补偿，`get_baro_temp()` 返回控制器温度。

## 五、高度系统的补充——激光测距

气压计在**低空**（< 2m）精度不足，此时用**激光测距（rangefinder）**辅助：

- `EKF_Rangefinder` 融合激光测距，提供厘米级低空高度
- `get_surface_tracking_climb_rate()` 用测距仪做"地形跟随"

高度估计的完整链条：**气压计（高空）+ 激光测距（低空）+ 加速度计（短时积分）→ EKF 融合**。

## 六、要点总结

1. 气压计通过"气压-高度"换算测高，测的是**相对高度**，需起飞归零
2. 驱动"写命令→等待转换→读结果"的时序在闭源库中
3. 数据 5Hz 滤波后进入 `EKF_Baro` 融合
4. 低空配合激光测距获得厘米级精度
5. 温度补偿对精度影响大，SPL06 内部已做补偿
